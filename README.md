# 🧬 Genesis

> A GitHub-inspired full-stack web application built while learning and experimenting with backend and full-stack development.

Genesis is an evolving project where I am applying the concepts I'm learning by building a real application rather than following a single tutorial from start to finish.

The project currently focuses on users, repositories, ownership, repository discovery, and the underlying relationships between these parts of the application.

---

## 🚀 Current Features

### 👤 Users
- User-based repository organization
- User-specific repository pages
- Repository ownership relationships
- MongoDB + Mongoose population for related data

### 📦 Repositories
- Create repositories
- View repositories
- View individual repository details
- Edit repositories
- Delete repositories
- Associate repositories with their owners
- Public/private repository visibility

### 🔍 Repository Experience
- Recently viewed repositories
- Dynamic repository pages
- User-specific repository listings

### ⚙️ Backend
- Express.js routing
- Express Router for organized routes
- Mongoose models and relationships
- Mongoose middleware
- Server-side validation
- Error handling
- Cookies and signed cookies

### 🎨 Frontend
- EJS dynamic views
- Reusable page structure
- Application navigation
- Custom styling
